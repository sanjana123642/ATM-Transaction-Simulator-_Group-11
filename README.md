# 🏧 ATM Transaction Simulator

A Java-based ATM simulation project built using **Object-Oriented Programming, Collections, Exception Handling, and Java Swing**.

The project simulates common ATM operations with controlled sample accounts and a simple graphical interface.

## ✨ Features

- 🔐 Customer login & PIN validation
- 💰 Balance enquiry
- 💵 Deposit & withdrawal
- 🧾 Mini statement & transaction history
- 🔎 Account & customer search
- 📊 Bank summary reports
- ⚠️ Transaction & balance validation
- 🚫 Custom exception handling
- 🖥️ Java Swing GUI

## 🛠️ Concepts Used

`Java` · `OOP` · `ArrayList` · `LinkedList` · `HashMap` · `TreeMap` · `Collections` · `Exception Handling` · `Swing` · `Enums`
